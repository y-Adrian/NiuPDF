# PDF 测试语料库

此目录只接受可公开分发、授权清晰的合成文档或专门设计的测试夹具。不得把用户论文、合同、身份证明、医疗资料或其他真实个人文档提交到仓库。若真实文件触发 bug，优先制作最小化、去敏的复现文件；必须留存原件时仅存放在本机忽略目录，并在 issue 中记录其 SHA-256，不提交文件内容。

## 类型覆盖

| ID | 类型 | 当前状态 | 主要检查 |
|---|---|---|---|
| C-01 | 500+ 页长文档 | 待生成 | 首页显示、连续滚动、内存、保存耗时 |
| C-02 | 扫描件 / 纯图像页 | 待生成 | 空文本搜索、缩放、内存；OCR 后续阶段验证 |
| C-03 | 加密与权限受限文档 | 待生成 | 密码提示、只读限制、错误密码、保存失败 |
| C-04 | 中日韩字体、竖排、嵌入字体缺失 | 合成样本已生成；缺失字体样本待补 | 显示、文本选择、搜索命中 |
| C-05 | 已有标准标注 / 表单域 | 待生成 | 不覆盖他人批注；读写和外部阅读器往返 |
| C-06 | 结构损坏或非规范 PDF | 待生成 | 优雅报错、不崩溃、不改坏源文件 |

`markup-regression.pdf` 也用于手工验证：选中第一行，打开右键菜单末尾的自定义颜色面板，从色盘选色并应用；确认原选区获得新颜色高亮。该文件是合成样本，已包含既有高亮、下划线和独立便签。

## 语料清单格式

每个夹具登记：文件名、生成脚本/来源、授权、SHA-256、页数、预期行为、触发的回归问题及其修复提交。性能语料记录机器型号、macOS/Xcode 版本、冷/热启动条件和重复测量结果。

所有合成 PDF 可通过 `python3 TestCorpus/generate.py` 重建。依赖只用于生成和检查夹具，不作为阅读器运行时依赖。`tests/test_corpus.py` 检查哈希与结构；`tests/check_interop_roundtrip.py` 通过 PDFKit、pypdf、PDFKit 执行 A→B→A 标注兼容检查，输出写在系统临时目录，不触碰源样本。

## 本机私有语料

不得提交的个人复现文件可放在 `TestCorpus/Private/`；该路径受仓库 `.gitignore` 忽略。日志只记录路径类别和 SHA-256，不记录文件名中可能含有的个人信息。

# Paperplane 功能清单

截至 2026-11-12（分支 `leading`，提交 `e083a31`）已完成并验证的功能。每项都经过单元测试或本地探针（事件注入、存储后重开、Ghostscript 渲染）验证；只有“手感”和沙盒中的文件面板等无法自动化的部分需要真机确认，见文末“已知限制”。

运行要求：macOS 13 或更高版本。翻译所选文字需要 macOS 14.4 或更高版本。界面为简体中文与英文，默认跟随系统，可在设置（⌘,）中切换。

## 打开与窗口

- 用 ⌘O、拖入窗口或从访达双击打开 PDF；可一次打开多个文件
- 多标签页与多窗口：⌘T 新建标签页，⌘N 新建窗口；标签页可拖出成独立窗口
- 开始页与最近文件（文件 ▸ 最近打开）；每个文件重开时回到上次的页码与缩放
- 打开有密码的 PDF，可把密码记在钥匙串中；在设置中可以忘记记住的密码
- 受权限限制的文件以只读方式打开，并显示提示条

## 阅读

- 缩略图、目录、批注列表三种侧边栏（⌥⌘1–4）
- 缩放：放大、缩小、实际大小、适合页面、适合宽度（⌘= ⌘- ⌘0 ⌘9）
- 页面布局：单页、单页连续、双页、双页连续（⌃⌘1–4）
- 翻页：上一页、下一页、首页、末页、跳到指定页（⌥⌘↑ ⌥⌘↓）
- 用户书签（⌘B），保存在应用中，按文件区分；可以重命名、删除
- 幻灯片放映：按键或单击翻页，Esc 退出
- 打印（⌘P）

## 搜索

- 全文搜索，在结果间跳转（⌘G / ⇧⌘G）；可用所选文字搜索（⌘E）
- 选项：区分大小写、全词匹配、正则表达式
- 搜索在后台分段进行，输入新内容时取消上一次搜索

## 选中文字后的工具

- 拖选文字后出现浮动工具条：高亮、下划线、波浪线、删除线、笔记、复制
- 翻译所选文字：使用系统翻译，以浮层显示（需要 macOS 14.4 或更高版本）
- 朗读所选文字，可以停止

## 批注

- 文字标注：高亮、下划线、波浪线、删除线。重叠的同类标注会合并；对已标注的文字再次使用同一工具，只擦除所选的那一部分
- 笔记：可以附在标注上，也可以作为便签放在页面任意位置；悬停时预览内容，单击打开编辑气泡
- 文本框：字体、字号、颜色，可设置背景与边框
- 手绘、矩形、椭圆、箭头：可调颜色、线宽、不透明度
- 标注工具栏：选择工具后保持有效，直到再次点击该工具或按 Esc；可存储常用样式
- 编辑批注：
  - 单击选中，⇧ 单击多选；
  - 拖动控制点缩放，拖动或用方向键移动；
  - ⌘C、⌘X、⌘V、⌘D 复制、剪切、粘贴、复制一份，可粘贴到其他页或其他文件；
  - Delete 删除，可批量删除。
- 批注列表：按类型、颜色、作者筛选，单击跳到批注所在位置
- 插入图片：可拖动、缩放
- 网址链接：在所选文字上添加，单击在浏览器中打开
- 签名：手写、键入或使用图片，可存储后反复使用
- 所有批注改动都可以撤销、重做（⌘Z / ⇧⌘Z）

## 页面管理

- 在缩略图中选择页面（⌘ 单击、⇧ 单击），拖动重排
- 旋转（⌘L / ⌘R）、删除页面
- 插入空白页，或插入其他 PDF 的页面（也可以把 PDF 拖到缩略图上）
- 提取页面为新文件；拆分文档，可以每隔若干页拆一份，也可以按页码范围拆分（每个范围一份）
- 裁切页面
- 水印：文字水印，可调字体、颜色、不透明度、角度，可选平铺
- 页眉页脚与页码：六个位置，可使用 {page} {pages} {date} {file} 占位符，可指定页码范围；带预览，可修改或移除
- 识别文字（OCR）：用系统 Vision 识别扫描页，支持中、英、日、韩；识别出的文字作为不可见文字层加入页面，之后可以搜索、选取、复制；可跳过已有文字的页面
- 涂黑：
  - 先标记要涂黑的区域，可以用涂黑工具画框、标记所选文字，或标记全部搜索结果；
  - 应用后，页面重画为图像，被标记的内容真正删除，可选同时识别其余文字；
  - 存储前可以撤销。
- 所有页面操作都可以撤销、重做

## 表单

- 填写 PDF 表单（文本域、复选框、单选按钮等，由 PDFKit 提供）
- 存储时修复 PDFKit 写错的单选组与复选框，在其他阅读器中显示正确；提取、拆分、合并出的副本同样会修复

## 文件操作

- 自动存储：每次改动后片刻、切换应用、打开其他文件或退出时存储；⌘S 立即存储；可在设置中关闭自动存储
- 设置、更改、移除打开密码；设置权限限制（分别控制打印、复制文字和图片、添加批注和填写表单、修改内容和页面）
- 合并文档（文件 ▸ 合并 PDF）：
  - 可以调整文件顺序；
  - 每个文件可指定页码范围；
  - 可逐页预览；
  - 也可以加入图片。
- 图片转 PDF（文件 ▸ 用图片新建 PDF）：页面可与图片同大，也可用 A4 或 Letter；横向图片使用横向页面
- 批量处理（文件 ▸ 批量处理）：对多个文件执行压缩、识别文字、加页码、加水印或导出文字；压缩后没有变小的文件不输出

## 导出（导出标签）

- PDF 副本：保留批注，或把批注扁平化进页面
- 可选减小文件大小：重新压缩并降低图片分辨率，文字与批注不变
- 导出页面为 PNG 或 JPEG，分辨率 72、150 或 300 dpi，可指定页码范围
- 导出文字为 TXT、RTF 或 Word（.docx）

## 已知限制

- 不能修改 PDF 中原有的文字。
- 不支持保留版式的 PDF 转 Word/Excel，导出 Word 只含文字。
- 不能新建表单域。
- 不支持证书数字签名，签名只是图片。
- 涂黑后的页面变为图像：文件会变大，原来的文字由识别结果代替；涂黑不处理书签和文档元数据。
- 批量处理会跳过加密文件，一次只能执行一个操作。
- 导出文字不能选页码范围；图片转 PDF 没有页边距选项。
- 合并出的文件不保留原文件的书签目录。
- 没有双指旋转手势；幻灯片放映不支持触控板手势翻页。
- 以下需要在真机或签名的沙盒应用中确认：
  - 操作手感；
  - 沙盒中的存储面板与文件夹权限；
  - 识别文字和涂黑之后，屏幕是否立即刷新；
  - 存储的文件在 Acrobat 中的表现。

# 开发路线图

需求来源见 [产品需求文档](产品需求文档.md)，工程约束见 [开发流程注意事项](开发流程注意事项.pdf)。本路线图采用竖切迭代：每期都交付一条可实际使用、可验证的读写链路。风险验证优先于堆叠功能。

## 阶段 0：需求与工程基线

- 归档原始需求和开发注意事项。
- 建立优先级路线、开发日志格式和测试语料库规则。
- 确认 macOS 原生构建链路和当前可运行的阅读器基线。
- 分发渠道确定为 Mac App Store；后续按 App Sandbox 与 security-scoped bookmark 设计。

## 阶段 1：PDFKit 技术探针与回归语料

- 准备大文档、扫描件、加密文档、中日韩字体/竖排、已有标注、损坏/非规范文件六类本地测试文件。
- 对 500 页以上文件记录首页显示耗时、滚动帧率、内存峰值和保存耗时。
- 验证本软件写出的高亮在 Preview / Acrobat / Chrome 的往返兼容性；验证外部标注可读、可编辑且不重复。
- 输出 PDFKit 的能力边界和是否需要替换引擎的决策记录。

## 阶段 2：安全文档模型与阅读基座（P0）

- 解耦文档模型、批注模型和 PDFKit 渲染适配层。
- 建立文件协调、修改冲突检测、临时文件写入、重开校验、原子替换与统一撤销栈。
- 阅读位置记忆、本地优先、沙盒文件授权与安全书签。
- 单页/双页/连续布局、适合宽度/页面、自定义缩放、多标签和多窗口。
- 缩略图、PDF 大纲与书签、输入即搜、结果上下文、匹配选项、标注列表。

## 阶段 3：标准批注竖切（P0）

- 标准 PDF 高亮、下划线、删除线、波浪线；选择后浮动工具条。
- 批注颜色预设、便签、自由文本。
- 批注列表跳转、修改、移动、缩放、复制和删除。
- 每种写入通过 A->B->A 往返验证；批注自动保存并可撤销/重做。

## 阶段 4：页面操作与合并竖切（P0）

- 页面新增、删除、旋转、重排和多选操作。
- 多文件拖入、合并预览、排序与安全保存。
- 对破损输入、保存中断、外部变更和 iCloud 协作执行回归检查。

## 阶段 5：P1 增强

- 同步分屏、夜间/护眼外观、历史回退、最近文件和收藏。
- 标注/文档导出、链接、页面提取/拆分/插入。
- 表单、签名、OCR、图片转 PDF、压缩、系统集成和完整快捷键。

## 阶段 6：P2 增强

- 演示与裁边、跨文档搜索、图章、批注回复与笔记摘录。
- 正文/图片编辑、水印、背景、表单创建、数字签名、元数据清理。
- 多端同步与云盘接入。

> 每个实现阶段开始前先在 `DEVELOPMENT_LOG.md` 建立带创建日期的 checklist；完成时填完成日期并建立一个聚焦的 Git 提交。阶段不得因为功能表上写着 P0 就绕过安全、兼容或性能验证。

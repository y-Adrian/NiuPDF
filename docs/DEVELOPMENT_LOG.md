| 2026-10-17 | 受限命令环境中的 `NSFileCoordinator` 对 `/private/tmp` 文件返回 Cocoa 256 | 安全文件协调回归无法在该限制下执行 | 在获批的 Xcode 测试执行环境中运行 `swift test`；两项临时副本保存测试通过，不降级产品协调访问 |
| 2026-10-17 | 打开时计算整份 PDF 的 SHA-256 会增加大文件 I/O | 可能影响很大的文件首次打开响应 | 目前保留强内容校验以避免静默覆盖；需在大文件性能阶段测量并评估后台计算/保存前等待方案 |
| 2026-10-17 | 命令行 Launch Services/Spotlight 对 Xcode 构建包注册失败，但 Xcode 图形会话可以正常启动应用 | CLI 的 `kLSNoExecutableErr` 不能代表 `.app` 无法运行；窗口已有用户文档打开，不能用它执行合成文件切换验证 | 已确认图形主窗口可启动；合成 PDF 沙盒授权与保存验证继续列为待办，不操作当前文档 |
| 2026-10-17 | PDFKit `findString` 为同步全文搜索，即使输入防抖，在超大文档上仍可能占用 UI 线程 | 搜索响应可能影响大 PDF 阅读流畅度 | 采用 250ms 防抖减少重复扫描；在 500 页性能阶段测量后再决定是否迁移到 PDFKit 异步查找 API |
